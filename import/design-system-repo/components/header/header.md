# Header

## Short description
Global navigation bar with brand logo, five primary links, and Account/Login utilities. The logo swaps automatically with the active brand mode.

## Content
- Logo links to the site home. One logo per brand ships in the markup; the theme reveals the right one.
- Primary nav: five short, single-word destinations (Home, Lifestyle, Mind, Money, Medical). The active page gets the underline via aria-current.
- Utilities: Account and Login sit right, icon plus label.
- Below tablet width the nav collapses into a hamburger drawer; nav and utilities repeat inside it.

## Marketing content notes
- Keep nav labels to one word where possible; the underline treatment reads best on short labels.
- Login and Account are fixed conventions across brand properties; avoid renaming per campaign.
- The header is not a campaign surface: no promos, badges, or announcements inside the bar.
