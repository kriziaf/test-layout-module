# Button Group

## Short description
The button atom in both palettes: Primary (filled) and Secondary (outline), each in Default and Inverse sets, with all five states.

## Content
- Labels: verb-first, two to four words ("Register now", "Find care").
- Primary is the one action you want taken; Secondary is the alternative path.
- Inverse set exists only for dark brand surfaces (Hero Inverse and similar).
- Disabled buttons should be rare in marketing pages; prefer hiding an unavailable action.

## Marketing content notes
- Never two Primaries side by side; the pair is always Primary plus Secondary.
- Button labels are not sentences: no punctuation, no "click here".
- Keep both labels in the same register (both actions, or both destinations).
