# Hero

## Short description
Page-opening split hero. Default pairs a light wash text panel with a photo; Inverse floats a dark brand panel beside the photo with accent buttons.

## Content
- Headline: the page's single value statement; one to two lines. This is the page's h1.
- Body: one paragraph. Default suits fuller copy (40 to 70 words); Inverse suits microcopy (under 30 words).
- Default actions: one primary button plus one text link.
- Inverse actions: accent primary plus accent outline secondary.
- Photo: environmental/people imagery; it is cropped to fill, so keep subjects centered.

## Marketing content notes
- One hero per page; it owns the h1.
- Inverse reads as product or sub-brand spotlight (the mockup shows "Freedom Fertility Pharmacy"); Default reads as the umbrella-brand statement.
- Keep Inverse body copy short — the dark panel amplifies text density.
