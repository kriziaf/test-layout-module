# List Item

## Short description
Four-across grid of short feature lockups under a left-justified heading block. Three types: Links (icon, heading, body, link), Stats (large figure, heading, body), Articles (two-line headline, body, link).

## Content
- Embedded header: eyebrow, section title, one intro line. No CTA.
- Links items: 32px icon (Phosphor), short heading, one to two sentence body, "Link Label" with arrow.
- Stats items: the figure is the hero (for example "99%"); heading and a single supporting sentence.
- Articles items: headline is clamped to two lines; write to fit rather than relying on the cut.

## Marketing content notes
- Keep the four items parallel in length and grammatical form; the grid amplifies inconsistency.
- Stats need a source or timeframe nearby if used in regulated contexts.
- Link labels should name the destination, not "Learn more".

## Accent variant
Circular accent-badge icon cards (folded in from the retired List Cards component). Icon badge (accent-filled circle, white glyph), bold heading, one to two sentence body — embeds the same left, no-CTA Heading Block header as the other variants.

- Keep headings short (3–6 words) so they don't wrap awkwardly against the icon badge.
- Icons are a recognition aid — reuse the same icon for the same concept across pages.
- Cards are non-interactive information blocks; pair with a separate CTA elsewhere on the page if a destination is needed.

## Content system
Follows the library's Services & Benefits technique (see
content-system.md): benefit-led headers, parallel structure. All
four variants (links, stats, articles, accent) share the SAME
six underlying benefit ideas, reshaped per variant format rather
than written independently — equal weight across the component
group, not per-variant improvisation.
