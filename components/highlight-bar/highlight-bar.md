# Highlight Bar

## Short description
Dark proof-point band, themed per brand (bg/brand-xstrong + inverse-default text). Two variants: Icon List (three icon+heading+body columns) and Metrics (three large stats with dividers).

## Content
- Title: one confident sentence, centered.
- Icon List items: short heading (3–6 words) + one to two sentence body explaining a capability.
- Metrics items: the number is the headline—keep it short (e.g. "94%", "48hr"); the label is one sentence of context, not a repeat of the number.

## Marketing content notes
- This band is for proof and confidence claims, not calls to action — there is no CTA slot by design.
- Metrics need a source or measurement window nearby if used in regulated contexts.
- Because the surface never changes with brand, copy here should read as company-wide fact, not brand-specific voice.

## Content system
Follows the library's Proof & Trust technique (see
content-system.md): confident, declarative stat claims. The
icon-list variant’s terminology is aligned with List Item’s
canonical benefit names where the concepts overlap, so the same
idea isn’t described two different ways across components.
